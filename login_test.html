Flask Login Service — Demo Frontend

This is a sample UI for demonstrating API authentication & profile retrieval.
Use any username/password from the backend's hardcoded user list.
Try johndoe / password123, alicew / alicepass321, ...
1. POST /api/login — User Login
Enter your email and password to request a login token.
If login is successful, the JWT token and expiry time will be displayed below.
2. POST /api/profile — Fetch Profile
Paste your Token & user ID below to retrieve the user profile.
Requires a valid JWT (from above), and a user ID, e.g. USER001.
